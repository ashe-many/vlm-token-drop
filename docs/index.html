Does the model look at the image?

A test of one claim from Seeing without Looking (arXiv 2605.22903): "Even at 75% token removal, accuracy remains nearly unchanged."

Code on GitHubPaper
Summary

The claim is correct. We removed 75% of the image tokens and accuracy decreased by only 4 points.

91.3%All image tokens
87.3%75% removed
50.7%All removed (same as a guess)

Qwen3-VL-4B · 4-bit · 300 POPE yes/no questions · 8 GB Apple M1

New The second image path (deepstack) does not cause this result. See ↓

1 The experiment

300 questions × 5 removal rates = 1500 answers.

All 300 questionsAnswer is Yes (147)

Up to 75% removal, the curve is almost flat. With no image tokens, the model says "No" to 99% of the questions.

3 Which path carries the image? New

Qwen3-VL sends image data on two paths. The paper does not examine them. We turned off one path at a time.

Path 1 carries the image. Path 2 alone also carries image data, but with path 1 present it adds almost nothing.

McNemar paired test. Path 1 only vs. normal: p = 0.25 (no difference). Path 2 only vs. no image: p < 0.001.

More details
Detail Checks, and differences from the paper
Checks
  • At 0% removal, the output is equal to the original model (difference: 0).
  • We remove the same tokens from the input, the deepstack copies and the positions.
  • The repository has all answers.
Differences from the paper
  • 8 GB Apple M1 and 4-bit weights. The paper uses a large GPU and 16-bit weights.
  • 300 questions with a fixed seed. The paper does not say which questions it used.
  • Kept tokens keep their original positions. The paper does not say.
  • We add 100% removal.
